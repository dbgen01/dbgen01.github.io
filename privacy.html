Privacy Policy

Last updated: 14 November 2026

Santvani Bot is a private tool used only by its owner. It uploads the owner's own finished videos, with their titles and descriptions, to the owner's own YouTube channels (Santvani and DB Cooper | Finance).

Use of YouTube API Services

Santvani Bot uses the YouTube API Services. By using Santvani Bot you agree to be bound by the YouTube Terms of Service. Your use of data through the YouTube API Services is also covered by the Google Privacy Policy (http://www.google.com/policies/privacy).

What data we access

With the owner's permission (Google OAuth, scope youtube.upload), Santvani Bot can only upload videos to the owner's channel. It does not read, collect or store any other YouTube data, and it does not access any data of other users or channels.

How the data is used

The access token is used only to upload the owner's videos on a daily schedule. No data is sold, shared with third parties, or used for advertising or analytics. No cookies are placed and no information is collected from visitors of this website.

Storage and security

The OAuth credentials are stored only as encrypted secrets in the owner's private GitHub repository and are never shown publicly. No YouTube API data is stored by Santvani Bot other than a simple log of which of the owner's videos have been uploaded.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page. When access is revoked, or if the owner stops using the tool, the stored credentials are deleted from the repository within 7 days. Any stored data can also be deleted on request through the contact options on the owner's YouTube channel.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
